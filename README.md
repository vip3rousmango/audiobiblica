# AudioBiblica

A comprehensive audio equipment knowledge management system designed for AV specialists. 

## Overview

AudioBiblica serves as a central repository for audio equipment manuals, guides, and documentation. It enables AV specialists to:

- **Upload & ingest** PDF manuals from audio equipment manufacturers
- **Extract knowledge** from documentation using AI-powered processing
- **Research & discover** equipment specifications from manufacturer websites
- **Build unified knowledge** accessible to MCP agents like DAW MCP for audio equipment control
- **Maintain a searchable catalog** of all audio equipment in your inventory

## Key Features

- **PDF Knowledge Extraction**: Automatic processing of equipment manuals
- **Manufacturer Research**: Web scraping and research from manufacturer sites
- **MCP Integration**: Unified interface for audio equipment control agents
- **Equipment Catalog**: Searchable database with technical specifications
- **Guide Library**: Beautiful, organized documentation for reference

## System Architecture

The system follows a modular approach with clear separation of concerns:

1. **Data Ingestion Layer**: PDF processing and knowledge extraction
2. **Research Layer**: Web scraping and discovery from manufacturer sites
3. **Knowledge Base**: Structured storage of equipment information
4. **MCP Interface**: Unified API for agent integration
5. **Desktop Application**: Cross-platform user interface
