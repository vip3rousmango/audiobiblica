# AudioBiblica documentation

AudioBiblica is a private, local-first catalog of your studio gear, with the manuals you own searchable by an assistant that runs on your own computer. It works with no account and no cloud service, and your data never leaves your machine.

- [GETTING-STARTED.md](GETTING-STARTED.md) — the walkthrough for musicians: installing Docker Desktop, starting the app, and the first five minutes.
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md) — the messages the app can show you and what to do about each one.
- [DEVELOPMENT.md](DEVELOPMENT.md) — architecture, environment variables, developer setup, and how to test.
